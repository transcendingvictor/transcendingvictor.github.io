ALWAYS?
Some fields are razed,
some girls are ugly,
some lies get through.

Some news hurts,
some rat sneaks in,
some giants die.

Some rock moves,
some tear escapes
and yes, yes, sometimes it rains.

Some good kiss is ignored,
some great painting breaks,
some sane man falls in love.

Some beast is beaten,
some evil happens nearby,
some story is forgotten.

Some things don't change:
There is no flat mountain,
nor a human so wise,
and no, you don't always win.

(clara)

Ví. Ab. Al.
